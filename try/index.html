A Markdown file, edited with your agent in real time.

A 30 second recording of the real Onionskin editor. Type in the file, comment on the words you want changed, and press Send once.

  1. Start typingThe preview switches to Edit, a plain text box on the file's Markdown source.
  2. Press EscBack in the preview, your new sentence is already rendered.
  3. Select and commentPoint at the exact words and say what you want.
  4. One SendYour edit is saved, the agent rewrites the words you pointed at, and History shows before and after.

About this recording: it is the real editor, version 1.0.1, on a sample file, driven by a script so the timing is steady. The agent's answer was written by Claude for this comment and sent through Onionskin's own reply command. Nothing here runs in your browser except the video.

To use it on your own files, paste this sentence into Claude Code or Codex:

Install Onionskin from https://github.com/abe238/onionskin
